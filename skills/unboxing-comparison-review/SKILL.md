# 开箱 / 对比评测模板 · Unboxing & Comparison Review

带货视频里最「可信」的两种形式。这个 skill 给出可复用的结构、拍摄清单和**公平对比规则**，避免「看起来像广告」或「贬低竞品」。

> Part of [ecommerce-video-skills](https://github.com/xianyu110/ecommerce-video-skills)

## 输入 Inputs

- 商品（及对比对象：同品牌旧款 / 「普通款」/ 用户自有竞品）
- 可做的真实测试（保温、承重、防水、续航……）及结果
- 时长（30s / 60s）、平台、出镜方式（真人 / 只拍手 / 纯图文）

## 模板 A · 开箱（30–45s）

| # | 段落 | 画面 | 口播要点 |
|---|---|---|---|
| 1 | 钩子 | 快递盒/包装特写，手撕开 | 「花 X 天等来的，看看值不值」或痛点提问 |
| 2 | 包装 | 俯拍开盒，清单平铺 | 盒子里有什么（只说实际有的配件） |
| 3 | 第一印象 | 手持转一圈、材质特写 | 手感、重量、做工（主观感受说明是主观） |
| 4 | 核心卖点演示 | 实际使用 | 1 个最强卖点 + 证明 |
| 5 | 小缺点 | 真实细节 | 说 1 个缺点，增加可信度 |
| 6 | 适合谁 | 场景画面 | 「适合……的人；不适合……」 |
| 7 | 行动号召 | 结尾卡 | 「链接放下面了」 |

## 模板 B · 对比评测（45–60s）

| # | 段落 | 画面 | 规则 |
|---|---|---|---|
| 1 | 钩子 | 两个产品并排 | 「同样装冰，8 小时后差多少？」（必须真的测过） |
| 2 | 选手介绍 | 并排平铺 | 竞品用「普通款 / 某价位常见款」，不点名贬低 |
| 3 | 测试设计 | 测试条件字幕 | 同环境、同起点、同时长；写在字幕里 |
| 4–6 | 逐项对比 | 分屏 / 前后对照 | 每项一个结论，数据来自实测 |
| 7 | 总结表 | 对比卡 | ✔ / ✘ 表，赢的输的都写 |
| 8 | 适合谁 + 号召 | 结尾卡 | 诚实推荐 |

**公平对比规则**：同条件测试 · 展示测试过程而非只给结果 · 不 P 图不加速 · 数据保留原始记录 · 不点名贬低竞品 · 不使用「秒杀一切」等绝对化说法。

## 拍摄清单 Shot checklist

- [ ] 俯拍开箱（手机固定在上方）
- [ ] 45° 手持转动 ×2
- [ ] 材质/Logo 微距 ×2
- [ ] 核心测试全过程（可延时）
- [ ] 测试结果特写（温度计、秤、计时器读数）
- [ ] 场景使用 ×2、结尾卡 1 张（`make_cards.py`）

## 转成可渲染的 storyboard

```json
{"shots": [
  {"video": "clips/unbox.mp4", "start": 2.0, "motion": "static", "line": "等了三天的保温杯到了，看看值不值。", "title": "开箱！"},
  {"video": "clips/flatlay.mp4", "line": "盒子里就一个杯子和一张说明书。"},
  {"image": "assets/compare-card.png", "fit": "blur", "line": "同样装满冰，放八小时后，左边已经化完了。", "sub": "同样装冰 8 小时|左边**化完了**"},
  {"image": "assets/end-card.png", "min": 3, "line": "适合通勤和健身党，链接放下面了。", "sub": "", "cta": "点击下方链接 ›"}
]}
```

对比卡可以用 `make_cards.py` 生成（如 `--points "左：普通款 · 已化完|右：本品 · 还有冰"`），或用姊妹仓库 [ecommerce-image-skills](https://github.com/xianyu110/ecommerce-image-skills) 出一张对比信息图。

## 提示词模板 Prompt template

```text
为 {商品} 写一条 {45} 秒的 {开箱 / 对比评测} 视频口播稿和分镜，按模板 {A/B}。
真实测试与结果（只能用这些）：{…}；对比对象：{普通款 / 旧款}；出镜：{只拍手}。
必须包含 1 个真实缺点和「适合谁 / 不适合谁」；不点名贬低竞品；不使用绝对化用语。
输出：分镜表 + storyboard.json。
```

## 检查清单 Checklist

- [ ] 所有数据来自真实测试，测试条件写在画面里
- [ ] 至少 1 个缺点、1 句不适合谁
- [ ] 竞品未被点名贬低；没有绝对化用语
- [ ] 若为合作/赠品测评，按平台要求标注「广告 / 合作」

## 常见问题与修复 Failure fixes

| 问题 | 修复 |
|---|---|
| 像硬广 | 加缺点和第一人称经历；减少形容词 |
| 对比不可信 | 展示测试过程、同框计时；不要只放结果图 |
| 素材不够 | 用商品图 + `motion` 补镜；对比卡用 `fit: blur` |
| 时长超 | 每个对比项只保留一个结论 |
