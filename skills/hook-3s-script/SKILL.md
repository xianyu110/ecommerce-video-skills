# 3 秒钩子脚本 · 3-Second Hook

前 3 秒决定用户会不会划走。这个 skill 只做一件事：**给同一个商品写 6–10 个不同类型的开场，每个都带台词、画面、花字**，方便直接 A/B。

> Part of [ecommerce-video-skills](https://github.com/xianyu110/ecommerce-video-skills)

## 输入 Inputs

- 商品是什么、给谁用（人群 + 场景）
- 1–3 个真实卖点（必须是用户确认过的事实）
- 平台与语言（中文 / 英文 / 双语）
- 可选：竞品常见说法、差评里的痛点、已有素材（图 / 视频）

## 步骤 Steps

1. **找一个最痛的场景**：从「用户在什么时候会烦」出发，不从「产品有多好」出发。
2. **按下表钩子类型各写 1 条**，每条 ≤ 18 个汉字（中文语速约 4–5 字/秒，3 秒说完）。
3. **配画面**：第一帧必须出现商品或痛点画面，别用 logo 片头。
4. **配花字**：花字 ≤ 10 字，是台词的「标题版」，不是逐字重复。
5. **合规自检**（见清单），删掉无法证明的说法。
6. **输出**：表格 + 推荐 Top 3 + 一句话说明为什么。

## 钩子类型 Hook patterns

| 类型 | 公式 | 示例（保温杯，演示） |
|---|---|---|
| 痛点提问 | 你是不是也…？ | 冰水不到中午就变温了？ |
| 反差 | 看着像 A，其实 B | 看着像普通水杯，晚上还能倒出冰块 |
| 结果先行 | 先给结果画面，再解释 | （先拍晚上倒出冰块）这是早上装的冰 |
| 数字 | N 个 / N 秒 / N 小时 | 通勤包里放了 8 小时，一滴没漏 |
| 场景代入 | 当你在 X 的时候 | 健身完想喝口冰水的时候 |
| 错误示范 | 别再这样做了 | 别再往包里塞会漏的杯子了 |
| 对比 | 左边 vs 右边 | 左边普通杯，右边这只，同时装冰 |
| 第一人称安利 | 我… | 我换了三个杯子，最后留下这只 |
| 悬念 | 最后一个最关键 | 选保温杯看这 3 点，第 3 点最多人忽略 |

> 示例中的「8 小时」「晚上还有冰」只有在你真的测过时才能用。

## 提示词模板 Prompt template（给任意大模型）

```text
你是电商短视频编导。为下面的商品写 8 个前 3 秒开场，每个用不同钩子类型。
商品：{商品名 + 一句话描述}
人群与场景：{谁，在什么时候用}
真实卖点（只能用这些，不要编造数据）：{卖点1}；{卖点2}；{卖点3}
平台：{抖音 / TikTok Shop / 视频号}，语言：{中文}
输出表格列：编号 | 钩子类型 | 台词（≤18字）| 第一帧画面 | 花字（≤10字）| 风险词检查
最后给出推荐 Top 3 及理由。禁止使用：最、第一、顶级、国家级、100%、根治 等绝对化或无法证明的说法。
```

English version: replace the language line with `Language: English (US), ≤ 10 words per line, casual creator tone`.

## 接入流水线

把选中的钩子写进 `storyboard.json` 第一个镜头：

```json
{"image": "assets/lifestyle.webp", "motion": "punch", "line": "夏天带冰水出门，不到中午就变温了？",
 "sub": "冰水不到中午就**变温**了？", "title": "冰水撑不到中午？"}
```

`motion: "punch"` 是开场快速推近，配合 `title` 花字弹出。

## 检查清单 Checklist

- [ ] 3 秒内说完（≤ 18 字，或英文 ≤ 10 词）
- [ ] 第一帧就有商品或痛点，不放 logo 片头
- [ ] 花字与台词不完全重复，≤ 10 字
- [ ] 所有数字/效果都有真实依据；没有绝对化用语（广告法）
- [ ] 不贬低具名竞品；对比用「普通款」
- [ ] 至少 3 种不同钩子类型可做 A/B

## 常见问题与修复 Failure fixes

| 问题 | 修复 |
|---|---|
| 开场太长，3 秒说不完 | 删形容词，只留「场景 + 痛点」 |
| 像广告，被划走 | 改成第一人称或提问；去掉品牌名，品牌放到第 2 镜 |
| 用了无法证明的数字 | 换成可视化演示（倒冰块）代替口头数字 |
| 所有版本都很像 | 强制每版不同钩子类型，并换第一帧画面 |
